# Test photos for app development

These photos are used to test the app's features (not to train models). Each photo's source, licence and hash are in `SOURCES.csv`.

The Unsplash License allows free use, including commercial use. It does not allow:
- selling unaltered copies;
- compiling the photos into a competing photo service.

Do not use these photos to train or evaluate machine-learning models. Lightly's Auto plan keeps training data separate and requires documented training rights.
