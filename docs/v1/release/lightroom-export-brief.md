# Lightroom reference exports: grain (M9) and vignette (G2) — one brief for the owner (2026-10-07)

Both effects are uncalibrated (`GRAIN_K`, `VIGNETTE_K` are first guesses in rendering-v2 F1/F2). No Lightroom export
exists locally (`experiments/presets/lr_kit/*/exports/` are empty), so no target is invented. These 33 exports are the
smallest set that fixes the constants and checks the result on the photos users saw.

**Common settings:** Lightroom Classic. Everything except the listed control neutral (kit-v2's `global` presets).
Export sRGB, 16-bit TIFF, no output sharpening, no metadata changes. "1200 px" = Resize to Fit, long edge 1200.
Name each file `<row>-<setting>.tif` (for example `V2-midpoint0.tif`) and put them in
`experiments/presets/lr_kit/kit-v2/exports/calibration/`.

**Photos (all in `experiments/presets/lr_kit/kit-v2/photos/`, rights cleared):** `fixture_smooth.jpg` (flat and muted
patches), `portrait_medium_02` (the M9 photo), `landscape_02` (the approved lake, the G2 photo) and **`fixture_flat.tif`**
(new: a uniform sRGB 119/119/119 card, 3000 × 2000, generated by us; regenerate with
`python3 -c "from PIL import Image; Image.new('RGB',(3000,2000),(119,)*3).save('fixture_flat.tif')"` if missing — the
folder is git-ignored).

## Vignette (Effects › Post-Crop Vignetting)
Measured on `fixture_flat`: the radial profile of the darkening (or lightening) from centre to corner, which fixes
`VIGNETTE_K`, the amount mapping, the midpoint and feather curves and the roundness exponent of rendering-v2 F1. The app's
Effects vignette maps to Highlight Priority with amount = −Amount, midpoint = Size, feather = Softness, roundness 0.

across sizes. **13 exports.**
