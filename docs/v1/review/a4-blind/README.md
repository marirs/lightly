# A4 hair edges: blind visual review (owner)

Open `experiments/depth/out/a4-review/index.html` (generated locally by
`experiments/depth/portrait_edges/make_review_page.py`; full-resolution images, not in git). 18 pairs, each the same
Change background result with two hair-edge treatments in random left/right order; full images with synchronised zoom and
scroll, plus full-resolution crops where the two differ most. Answer A, B, no difference or neither acceptable, mark any
fringe you see, then copy or download the answers. The key stays closed until the answers are recorded.

**What this review is:** a visual assessment on its own. It does not rescore the candidate's experiment, which FAILED its
pre-set gate and stays recorded as failed (`experiments/depth/results/hair-fresh/README.md`). A preference or a tie
between two defective edges is not release acceptance: the A4 outcome stays "no visible teal/grey fringe", and any pair
marked "neither acceptable" or with a fringe keeps A4 open whatever the preferences. Your review can run while other work
continues. (The pair images in this folder are the earlier crops; the page above supersedes them.)
