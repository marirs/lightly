# Amendment 2026-10-05: Develop browsing, preset names, Auto notice, Crop (owner feedback from iPhone testing)

Requested by the owner on 2026-10-05; changes the approved design (`docs/ui/app/`) only where listed. Everything else
stays as approved. The prototype files are not edited; this record is the reference for these states.

## Develop
1. **Browsed category:** a 2 pt orange underline (light `#C25E00`, dark `#FF9F43`) under the selected category's name,
   2 pt below the text, as wide as the name. It moves immediately when another category is chosen; the photo and the
   applied preset do not change.
2. **Applied category:** the 5 pt blue dot means only "this category contains the applied preset" (Favourites too, when
   the applied preset is a favourite). It does not move while browsing.
3. **No counts beside category names** (tabs, wrapped tabs and the tablet list). The applied or shown preset's
   position ("37 / 518") stays once, beside its name.
4. **Applied preset while browsing elsewhere:** at rest the name row shows the applied preset's name and, below,
   "Applied from <category> · <its position>" (e.g. "Applied from Landscape · 8 / 518"). No position beside the name
   then: it would read as the browsed ruler's (owner request, second round 2026-10-05). While the ruler is dragged the
   name and the position beside it are the browsed ruler's stop, and the context line is empty. "Original" is shown
   only while the ruler is dragged to stop 0 (the preview then is the original). Star and Amount act on the named
   preset. A drag released where it started is a cancel: nothing is recorded and the applied preset stays.
5. **Undo/Redo:** after Undo or Redo the underline returns to the applied preset's category; applying from the browsed
   category (Favourites included) keeps it browsed.
6. **Category row beside Auto:** no label is half hidden beside Auto. The row has 18 pt margins (past its 16 pt edge
   fade), and it scrolls so the tab before the selected one starts at the leading margin, fully visible (the
   prototype's "selected tab 120 pt in" left the previous tab cut under the fade). The first two tabs scroll the row to
   its start.
7. **Accessibility:** a category's label is its name; the browsed one has the selected trait; the applied one's value is
   "Contains the applied preset". Underline and dot differ in shape, not only in colour.

## Preset names
Readable names from `shared/look-pack/names/display-names.json` (rules in `shared/look-pack/display_names.py`), the same
on both platforms; ids, versions, recipes, favourites and saved edits unchanged. Examples: "05 Nude Tones 05" →
"Nude Tones 5", "02 Hiking 02" → "Hiking 2", "16 - (Portrait) Kodak 2" → "Kodak 2", "CC20 - Earthy | Heated" →
"Earthy · Heated". Names that would merge two different presets keep their catalogue names (77 groups) for now;
proposed: every shared label gets " · A", " · B", … in catalogue order (97 labels, 198 presets, preview in
`docs/v1/release/preset-name-collisions.md`), applied after owner approval.

## Auto
No standing "Automatic correction isn't available…" notice in the Develop panel. Tapping the unavailable Auto shows a
toast: "Automatic correction isn't available. Presets still work." Nothing promises availability. Auto remains an
unfinished requirement.

## Crop
Free crop: drag any corner or edge independently; drag inside to move the rectangle; aspect presets lock the ratio;
Free returns to unconstrained. (Implementation record follows with the Crop change.)
