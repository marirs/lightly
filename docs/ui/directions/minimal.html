Lightly — Direction A, minimal pass

Same navigation and editing behaviour as before: a seven-tool dock, a detent ruler for preset stops (hold still to fine-tune), and tabs for sub-tools. What changed is the visual layer. Surfaces are neutral, the type is the system sans-serif, and controls are flat. There is one selection colour and only one solid button (Save copy). The top bar sits on the surface, so the photo is never covered, and the active-tool panel is reduced to the essentials.
